# MHD Iranian Gaming Hub

نسخه آغازین پورتال گیمینگ فارسی با Next.js و JavaScript.

## پیش‌نیاز
- Node.js نسخه 20 یا جدیدتر
- npm

## نصب و اجرا در ویندوز
1. فایل ZIP را استخراج کنید.
2. پوشه `mhd-gaming-hub` را در VS Code باز کنید.
3. از منوی Terminal گزینه New Terminal را بزنید.
4. دستور زیر را اجرا کنید:

```bash
npm install
npm run dev
```

5. در مرورگر آدرس `http://localhost:3000` را باز کنید.

برای ساخت نسخه production:

```bash
npm run build
npm start
```

## وضعیت نسخه
- صفحه اصلی و مسیرهای اصلی ساخته شده‌اند.
- اطلاعات بازی و خبرها نمونه نمایشی هستند.
- ابزار PC Checker در این مرحله فقط مشخصات را دریافت و نمایش می‌دهد؛ هنوز مقایسه واقعی انجام نمی‌دهد.
- حساب کاربری، انجمن، پرداخت و اتصال API در مراحل بعدی پیاده‌سازی می‌شوند.

## ساختار
- `src/app`: مسیرها و صفحات Next.js
- `src/components`: اجزای قابل استفاده مجدد
- `src/data`: داده‌های نمونه
- `src/lib`: توابع کمکی آینده
- `public`: فایل‌های عمومی مانند تصویر، آیکون و فونت
